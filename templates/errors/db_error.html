Error de Conexión con la Base de Datos

¿Por qué ocurre esto?

La aplicación no pudo establecer conexión con el servidor Azure SQL Database. Esto suele ocurrir por las siguientes razones:

  • Contraseña o credenciales incorrectas: La contraseña configurada en el archivo .env (variable AZURE_SQL_ADMIN_PASSWORD o DATABASE_URL) o en las configuraciones de Azure App Service no coincide con la configurada en el servidor.
  • Pausa automática del servidor (Serverless): La base de datos es de tipo Serverless y está despertando de su suspensión automática (esto puede tardar entre 30 y 60 segundos en el primer intento).
  • Reglas de Firewall de Azure SQL: El firewall del servidor SQL está bloqueando la conexión. Asegúrate de habilitar la opción "Permitir que los servicios y recursos de Azure accedan a este servidor" en el portal de Azure.
